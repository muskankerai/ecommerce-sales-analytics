# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to identify sales trends, customer behavior, product performance, and country-wise revenue.

The project uses Python, SQL, and Power BI to perform data cleaning, analysis, and visualization.

## Objectives

- Analyze overall sales performance
- Identify top-performing products
- Analyze monthly revenue trends
- Identify top customers
- Analyze country-wise sales
- Calculate key business metrics
- Build an interactive Power BI dashboard

## Dataset

The project uses the Online Retail dataset containing e-commerce transaction records.

The dataset includes information such as:

- Invoice Number
- Product Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

The cleaned dataset is provided in compressed CSV format.

## Project Workflow

1. Load the original dataset
2. Clean missing and invalid records using Python
3. Remove duplicate records
4. Calculate revenue
5. Perform exploratory data analysis
6. Perform SQL-based analysis
7. Create an interactive Power BI dashboard
8. Generate business insights
